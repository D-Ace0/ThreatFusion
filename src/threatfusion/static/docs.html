Case endpoints

POST /api/cases — local import of title, source_name, text
POST /api/cases/demo — fictional walkthrough
GET /api/cases — case summaries
GET /api/cases/{id} — full case
PATCH /api/cases/{id}/indicators/{indicator_id} — disposition and note
POST /api/cases/{id}/enrich — selected batch job
GET /api/jobs/{id} — progress
POST /api/jobs/{id}/cancel — cancel
GET /api/cases/{id}/report?format=json|csv|pdf — brief
DELETE /api/cases/{id} — remove local case

Single IOC endpoints

GET /api/demo — fixture list
GET /api/analyses/{id} — saved analysis
GET /api/analyses/{id}/report?format=json|pdf — export
GET /api/history?limit=20&offset=0 — pagination
DELETE /api/history — delete all local history/cache
